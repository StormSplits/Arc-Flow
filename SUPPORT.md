# Support

## Before you ask

Most "how do I…" questions are answered in the app itself — check
**Settings → Help** and the onboarding guide (Settings → Help → Replay
Onboarding) first.

## Getting help

| I have… | Go here |
|---|---|
| A bug or something that behaves incorrectly | [Open a bug report](../../issues/new?template=bug_report.yml) |
| A crash | [Open a crash report](../../issues/new?template=crash_report.yml) |
| An idea for a new feature | [Open a feature request](../../issues/new?template=feature_request.yml) |
| A question that isn't a bug or a feature idea | [Open an issue](../../issues/new) describing what you're trying to do |
| A security or privacy-sensitive report | See [SECURITY.md](SECURITY.md) — please don't use a public issue |
| Anything else | Email shubhamsinghania0508@gmail.com |

## What to include

Whatever the channel, a few details go a long way:

- Your Arc Flow version (Settings → About)
- Your Windows version
- How you installed Arc Flow (MSI installer, portable ZIP, etc.)
- What you expected to happen, and what happened instead

See the README's [Including logs and screenshots safely](README.md#including-logs-and-screenshots-safely)
section before attaching a log file or screenshot.

## Response times

Arc Flow is maintained by a small team, so please be patient — we read
every issue, but response times can vary. Security reports (see
[SECURITY.md](SECURITY.md)) are prioritized.
